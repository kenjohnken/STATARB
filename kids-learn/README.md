# 小小學習樂園 (kids-learn)

給 4–5 歲小孩的中英雙語看圖跟讀 App。純靜態網頁(PWA)，不需要打包工具，不需要後端。

## 功能

- 4 個分類、35 個詞：動物、水果、顏色、交通工具
- 每個詞：大圖 + 程式動畫、中文(可顯示注音)、英文
- 🔊 聽發音(瀏覽器內建語音合成，中文 zh-TW、英文 en-US)
- 🎤 跟我唸：語音辨識，判定刻意放寬
  - 通過 → 星星 + 彩帶 + 稱讚
  - 失敗 1 次 → 再示範一次，鼓勵再試
  - 失敗 2 次 → 給「參與星」並繼續，不讓小孩卡關
  - 瀏覽器不支援辨識，或在設定選「只錄音回放」→ 錄 3 秒，播放示範再播放小孩的聲音
- 家長設定(需答對加法題)：注音開關、語速、跟讀模式、辨識統計、清除進度
- 進度存在瀏覽器 localStorage，不上傳任何資料

## 執行

```bash
cd kids-learn
python3 -m http.server 8000
# 電腦瀏覽器開 http://localhost:8000 (localhost 視為安全環境，可用麥克風)
```

手機要用麥克風，網址必須是 **HTTPS**(區網的 http://192.168.x.x 不行)。可選：

- 部署到任何 HTTPS 靜態網站(GitHub Pages、Cloudflare Pages、Netlify 等)
- 臨時用隧道工具把電腦的 8000 埠轉成 https 網址

部署在 HTTPS 後，Service Worker 會啟用，之後可離線使用，也能「加到主畫面」。
改版後請調高 `sw.js` 的 `CACHE` 版本號。

## 加詞、換素材

只改 `words.js`：

```js
{ id: 'cat', zh: '貓', zy: 'ㄇㄠ', en: 'cat', img: '1f431', anim: 'wiggle', altZh: ['毛'] }
```

- `zy` 每個字一組注音，用空格分隔，數量必須等於字數
- `img` 對應 `assets/twemoji/<img>.svg`；要換成自己的插圖，放進 `assets/` 並把 `IMG()` 路徑規則或檔名改掉即可
- `anim`：bounce / wiggle / grow / swim / float / drive / pulse
- `altZh`：中文辨識額外接受的同音字(選填)

## 已知限制(誠實說明)

- **尚未用真實小孩的聲音和真實手機測試。** 自動測試用的是模擬的語音 API，只驗證流程、比對邏輯和畫面，沒有驗證辨識準確率。
- 幼兒語音的辨識準確率未知。家長設定裡有「辨識統計」，用一週觀察通過率，再決定要不要調整放寬程度。
- 語音合成的音色取決於裝置，若裝置沒有 zh-TW 語音可能會用其他中文語音；沒有任何語音時，發音按鈕會沒聲音。
- iOS Safari 的 `webkitSpeechRecognition` 行為我沒有實測，若不穩定請到設定改為「只錄音回放」。
- Chrome 的語音辨識會把聲音送到 Google 伺服器；要完全不外傳請用「只錄音回放」。
- 注音由我依一般讀音撰寫，請家長瀏覽一遍有無錯誤。
