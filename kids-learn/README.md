# 小小學習樂園 (kids-learn)

給 4–5 歲小孩的中英雙語學習 App。純靜態網頁(PWA)，不需要打包工具，不需要後端。

## 功能

首頁 5 個入口：

| 入口 | 內容 |
|---|---|
| 📖 學單字 | 4 分類 35 詞(動物/水果/顏色/交通)。看圖、聽發音、跟著唸(語音辨識，判定放寬) |
| 🔍 找一找 | 聽到詞，從 3~4 張圖點出正確的。8 回合；點錯會說出「這是 X」，錯兩次提示答案 |
| 🎴 翻翻樂 | 翻牌配對，簡單 3 對 / 普通 4 對 / 挑戰 6 對，翻開時念出名稱 |
| 📚 聽故事 | 2 個互動故事：《小猴子去野餐》《小汽車去旅行》。每頁有旁白，任務有點選、拖曳、跟讀三種 |
| 📒 貼紙簿 | 完成遊戲或故事得到貼紙(共 22 張，每個故事有專屬貼紙) |

共通設計：

- 右上角「中文 / English」一鍵切換，所有畫面跟著換語言
- 不設時間限制，答錯不扣分；提示機制保證小孩不會卡關
  - 跟讀：失敗兩次給參與星
  - 故事點選：錯兩次目標會發光
  - 故事拖曳：錯兩次目標發光，錯四次自動示範
- 故事場景中的物件都可以點，點了會念出名稱
- 家長設定(需答對加法題)：注音、語速、跟讀模式、辨識統計、清除進度
- 進度存在瀏覽器 localStorage，不上傳任何資料

## 執行

```bash
cd kids-learn
python3 -m http.server 8000
# 電腦瀏覽器開 http://localhost:8000 (localhost 視為安全環境，可用麥克風)
```

手機要用麥克風，網址必須是 **HTTPS**(區網的 http://192.168.x.x 不行)。部署到任何 HTTPS 靜態網站即可(GitHub Pages、Cloudflare Pages、Netlify 等)。
部署在 HTTPS 後，Service Worker 會啟用，之後可離線使用，也能「加到主畫面」。改版後請調高 `sw.js` 的 `CACHE` 版本號。

## 檔案結構

| 檔案 | 用途 |
|---|---|
| `words.js` | 詞庫、UI 圖示、貼紙清單 |
| `stories.js` | 故事資料(場景物件位置、旁白、任務) |
| `core.js` | 共用核心：儲存、語音合成、語音辨識、比對、路由、獎勵畫面 |
| `learn.js` | 分類選單、學單字 |
| `games.js` | 找一找、翻翻樂 |
| `story.js` | 故事清單、故事引擎 |
| `app.js` | 首頁、貼紙簿、家長設定、啟動 |

## 加詞

改 `words.js`：

```js
{ id: 'cat', zh: '貓', zy: 'ㄇㄠ', en: 'cat', img: '1f431', anim: 'wiggle', altZh: ['毛'] }
```

- `zy` 每個字一組注音，用空格分隔，數量必須等於字數
- `img` 對應 `assets/twemoji/<img>.svg`
- `anim`：bounce / wiggle / grow / swim / float / drive / pulse
- `altZh`：中文辨識額外接受的同音字(選填)

## 加故事

在 `stories.js` 新增一筆，場景為 4:3，物件位置用百分比：

```js
{ id: 'banana', img: '1f34c', x: 46, y: 38, s: 16, word: 'banana' }   // x,y = 中心點，s = 寬度
task: { type: 'tap', target: 'banana', moveTo: 'monkey', prompt: {zh, en}, done: {zh, en} }
task: { type: 'drag', item: 'bus', to: 'stop', prompt, done }
task: { type: 'say', word: 'dog', prompt, done }
```

背景可用：meadow 草地、road 馬路、park 公園、farm 農場、beach 海邊。新圖檔要放進 `assets/twemoji/`。

## 已知限制(誠實說明)

- **尚未用真實小孩的聲音和真實手機測試。** 自動測試(95 項)用的是模擬的語音 API，只驗證流程、邏輯和畫面，沒有驗證辨識準確率和實際語音品質。
- 幼兒語音的辨識準確率未知。家長設定裡有「辨識統計」，用一週觀察通過率再調整。
- 語音合成的音色取決於裝置；裝置沒有 zh-TW 語音時可能用其他中文語音，完全沒有語音時就不會發聲。
- iOS Safari 的語音辨識我沒有實測，不穩定的話請到設定改為「只錄音回放」。
- Chrome 的語音辨識會把聲音送到 Google 伺服器；要完全不外傳請用「只錄音回放」。
- 拖曳在手機上的手感(目標範圍大小)要實際讓小孩玩過才知道是否合適。
- 注音與故事文字由我撰寫，請家長瀏覽一遍。
- 圖片是 emoji 拼貼風格，不是手繪繪本。
